# Freehold documentation

Freehold is a free, open-source, self-hosted work tracker. It is a Jira alternative you run on your own
infrastructure, with no licence server, no telemetry, and a complete data export.

**Version 0.1.0-beta.** Phase 1 is built. See the [feature matrix](product/feature-matrix.md) for exactly
what works today and what does not.
